# Module 3 — Framework Demos

Quick, runnable demos of **two** agentic AI frameworks — no API key needed.

| Demo | Framework | What It Shows |
|------|-----------|---------------|
| `langchain_demo.py` | **LangChain** (ReAct Agent) | Single agent with tool use loop |
| `crewai_demo.py` | **CrewAI** (Multi-Agent Crew) | 3 agents collaborating sequentially |
| `visualize.html` | **Visual Architecture** | Interactive diagram of both frameworks |

## Quick Start

```bash
cd framework-demos
pip install -r requirements.txt   # rich, python-dotenv only
python langchain_demo.py          # LangChain ReAct demo
python crewai_demo.py             # CrewAI multi-agent demo
open visualize.html               # Visual architecture diagram
```
